# XCPC 报销材料整理工具

依据《2026 年 CPC 参赛注意事项》（东南大学 · CPC 队员会议材料）开发的本地报销材料整理工具，技术栈 **Vue 3 + Vite**，无需后端，数据仅保存在本机浏览器（localStorage），不会上传。

## 使用

```bash
npm install     # 首次安装依赖
npm run dev     # 本地开发，默认 http://localhost:5173
npm run build   # 打包到 dist/（纯静态，可任意部署或直接双击 dist/index.html）
```

## 功能

| 页面 | 说明 |
| --- | --- |
| 总览与流程 | 行程信息（比赛名称 / 日期 / 负责人）、发票抬头税号一键复制、报销等级与时效提醒、四步办理流程勾选 |
| 同学清单 | 参赛同学一卡通号 + 姓名，支持批量粘贴、导出 CSV（Excel 不乱码）、复制文本 |
| 差旅审批单 | 按《东南大学公务出差财务核算审批单》模板自动生成：出差人名单取自同学清单、起讫日期取自行程信息，交通/住宿/补助选项可视化勾选；支持页内 A4 预览、直接打印、下载标准 .docx（Word/WPS 可打开微调） |
| 材料打包 | **按队伍打包**：填队名后按「往返交通 → 赛站住宿」添加行程（交通分飞机 / 高铁 / 市内交通，可加多段；往返一起支付的材料放同一段即可），按各类型材料要求上传（必附/按需标注），每类还支持添加任意多个自定义材料项；**每个文件单独设置**：去程/返程勾选框（往返一起就两个都勾）、金额（PDF/OFD/图片自动识别填入，可改）、归属队员（识别到姓名会自动勾选）；支持文本型 PDF 提取文字、扫描件/图片型 PDF 抽取页面图片 OCR、OFD 发票解析文字、图片 OCR（中文模型已随工具内置，离线可用；以 file:// 直接打开 dist 时浏览器禁止 Worker，请通过 http 访问或改用服务器识别）；也可在材料打包页开启「服务器端模型」：配置 OpenAI 兼容视觉接口（地址/密钥/模型名，仅存本机）后，图片与扫描件改由服务端大模型识别（材料含个人信息请确认服务端可信；失败自动回退本地），文本型 PDF 与 OFD 仍用本地解析；个别浏览器不支持扫描件 PDF 渲染时请截图转图片上传；底部「材料准备进度」逐人检查去程/返程/住宿发票归属，并自动检查每张发票抬头是否含「东南大学」/ 税号、机票发票与订单记录是否含「经济舱」字样（问题项进入进度提醒、打包确认与报告待办）；**合并为一个 PDF**：全部材料按清单顺序合成一份大文档（图片排 A4、PDF 无损合并），下载后即可打印；**打包 ZIP** 自动规范命名（含队伍信息、同学清单 CSV、差旅审批单、核对报告）；**赛站汇总**（负责人用）：上传各队 ZIP 自动解包合并为赛站总包（含负责人统一收取的参赛费材料），每队一个文件夹并附汇总说明 |
| 核对报告 | 基本信息、材料打包明细、办理流程状态、待办事项、群内消息模板；可打印 / 复制 Markdown / 下载 TXT |

数据可通过顶栏「导出数据 / 导入数据」在同学之间传递接力填写。

## 目录结构

```
├── index.html              # Vite 入口
├── vite.config.js          # base: './'，打包后可静态部署
└── src/
    ├── main.js             # 应用入口
    ├── App.vue             # 布局 + Tab 切换 + toast
    ├── store.js            # 响应式状态 + localStorage 持久化
    ├── style.css           # 全局样式（含打印样式）
    ├── data/
    │   └── report.js       # 核对报告（文本 / Markdown）
    ├── utils/
    │   ├── misc.js         # 金额格式化、剪贴板、下载、CSV 等
    │   ├── zip.js          # 极简 ZIP 打包器（无第三方依赖）
    │   └── unzip.js        # ZIP 解包（store / deflate，UTF-8 / GBK 文件名）
    └── components/         # 各页面组件
```

> 材料要求以财务处与教练的最新通知为准；工具仅作整理提醒，不替代官方流程。
